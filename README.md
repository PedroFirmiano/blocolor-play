# Blocolor

Jogue no navegador: **https://pedrofirmiano.github.io/blocolor-play/**

Quebra-cabeça de encaixar peças e juntar cores para revelar o desenho escondido
embaixo do tabuleiro. Funciona no celular — abra o link e adicione à tela de
início para jogar em tela cheia.

Este repositório contém **apenas o build compilado**, publicado para que o jogo
tenha um endereço público. O código-fonte é privado.
